# v0.2 工作台升级记录与验收清单

## 本轮目标

把球体小样升级为可导入素材、可调流场、可编辑关键帧的粒子动画工作台。以桌面浏览器本地运行为主，保留现有截图、观察视角与 720p 自由录制功能。以下功能已完成实现；最新自动测试 52 项通过，真实浏览器现场验收由本轮后续记录补充。

## 用户花朵图片展示

- 原图已复制为 `public/examples/particle-flower-reference.jpg`：736 × 981、RGB、87,822 字节，作为图片示例展示，原文件不修改。
- 默认与顶部示例入口使用该图片，配置原色、80,000 粒子、12 秒循环：初始原形停留 → 侵蚀卷曲与拉丝 → 末段淡出 → 反向还原，配合轻微素材缩放和旋转。具体阶段由关键帧时间线定义，可以继续编辑。
- JPG 没有透明通道，黑背景像素保留并参与采样；未加入自动黑底抠除。
- 聚合后的图片是二维薄平面，侧面较薄；消散可以进入三维空间。未实现单图三维重建，不能声称从这张图片恢复了立体花朵。
- 该图片是用户提供的静态图片；目前没有花朵参考视频文件，展示依据文字与图片设计，不声称已对照视频逐帧还原。

## 1. 时间轴与播放

- 底部统一使用秒时间轴，显示当前时间和总时长，不再用百分比表示动画进度。
- 初始自动播放完整聚散循环；空格播放 / 暂停，输入文字或编辑数值时不触发快捷键。
- 拖动时间轴暂停并定位；暂停后相机和参数仍然可操作。
- 播放倍率改变当前动画推进速度；粒子运动速度独立控制流场变化。
- 支持循环开关、回到开头，保持单一播放任务。

## 2. 可用的素材导入窗口（本轮优先）

- 左上提供清楚的导入入口，打开窗口后可选择文件或拖入 PNG / JPG / JPEG / GLB。
- 窗口说明支持的文件与处理方式，提供花朵图片和多网格 GLB 示例的一键加载与下载。
- 图片过滤透明区域、保留比例和原色；JPG 保留背景；图片组成薄平面粒子，可向三维空间消散。
- GLB 对有效静态网格按世界空间表面积采样，保留多网格相对变换、顶点色 / 材质基色 / 基础色贴图。
- 成功后才替换原场景；损坏、不支持、完全透明或无有效静态网格时显示中文原因。
- 连续导入以最后一次请求为准；同一文件可重复选择；录制中锁定素材替换。
- 显示素材名、类型、处理状态、实际绘制数量与降级提示。素材处理完全在本地完成。

## 3. 六种效果与聚散调节

- 保留径向扩散、噪声漂浮、旋涡消散，增加定向吹散、波浪消散与流场侵蚀。
- 保持固定原始位置与稳定种子，任意反向变化准确还原素材。
- 原色 / 统一色可切换；默认黑色背景，柔和光晕真实进入画布。
- 流场侵蚀提供侵蚀强度、流场尺度、流动方向、拉丝强度、短拖尾及末段淡出。
- 空间相关的局部变化形成孔洞和稀疏区，分离后形成弯曲细流；效果参数必须真实影响渲染。
- 除预设外，可调当前形态并把聚散、缩放和旋转写入关键帧。

## 4. 关键帧动画

- 每帧记录时间、聚散形态、整体缩放及素材 XYZ 旋转，素材旋转独立于观察相机。
- 可在当前时间添加关键帧，点击选择、修改、删除，平滑插值。
- 通用片段默认 6 秒：0 秒聚合 → 3 秒消散 → 6 秒聚合；本轮用户花朵展示专用片段为 12 秒。可调整动画总时长。
- 关键帧与效果参数一并导出 / 导入 JSON；文件不包含原始素材。
- 播放和录制使用同一画布动画，录制保留关键帧变化。

## 验收方法

1. 用透明花朵 PNG 验证比例、粉色花瓣 / 黄色花蕊和空白区域过滤；用 GLB 示例验证三个网格的相对位置与原色。
2. 测试不支持文件、损坏文件、透明图片、快速连续导入，失败保留旧素材。
3. 以秒定位和空格暂停 / 继续，确认暂停后视角可动，默认播放有运动。
4. 给缩放、旋转打关键帧，检查中间插值、端点和循环；确认 JSON 可以恢复动画。
5. 在六种效果下检查可辨认差异，侵蚀 / 拉丝 / 拖尾 / 淡出参数产生变化，回到开头没有历史残影。
6. 通过 TypeScript、生产构建和相关自动测试；浏览器实际检查画面与错误日志。记录未完成的长时间稳定性验证，不把未测项目标为通过。
