原模型的金属、粗糙度等外观被转换为粒子可读取的基础色。粒子展示保留青绿铜锈和暖金颜色，使用表面积加权采样；它不渲染完整实体表面的灯光反射。

## 默认展示与使用

默认显示 100,000 个原色粒子，使用 16 秒可编辑循环：0–3 秒稳定正面，6 秒转至 32°，随后流场消散，10.8–11.6 秒完全散开，14 秒恢复原形并停留至循环结束。首末帧的形态、缩放和旋转一致。

左键拖动观察三维结构，滚轮缩放，右键平移；空格暂停或继续。右侧可调整密度、外观和运动，底部时间轴可定位或改帧。素材卡和导入窗口均提供“青铜方鼎”加载入口及 GLB 下载；切换其他素材后可重新载入。

## 重跑导出与验证

在项目根目录运行，需安装 Blender 并使 `blender` 命令可用：

```powershell
blender --background --disable-autoexec --python scripts/export-ding-model.py -- --source ../青铜方鼎_v002.blend
npm test
npm run build
```

导出脚本默认目标为 220,000 个三角面、保留 1,000 面以下小网格、贴图最长边 2048；可通过 `--target-triangles`、`--preserve-below`、`--texture-size` 调整。脚本仅写 GLB 及其元数据，并核对源 `.blend` 哈希未变。改变导出规格后应同步审阅资产回归中的规格断言。
