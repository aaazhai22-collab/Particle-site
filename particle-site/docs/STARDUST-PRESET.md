# 繁花星尘 · 渐蚀

记录日期：2026-10-25。根据用户两张参考图新增独立视觉预设，目标是细密晶亮的原色颗粒、粉色花瓣与黄橙花心的颜色层次，以及局部孔洞、卷曲和渐隐。它不覆盖白百合、花瓣微流或已有六种效果，也不改变默认白百合示例。

## 操作

- 在左侧“视觉预设”选择“繁花星尘 · 渐蚀”：应用到当前素材，保留素材与观察视角，从 0 秒开始播放 36 秒循环。
- 选择“粉色花朵参考演示”：载入已有粉色立体花朵 GLB，应用新预设并使用特写视角。该入口会替换当前素材；普通预设按钮不会。
- 空格播放或暂停，底部秒制时间轴定位；右侧可调整“晶亮颗粒”、亮核、泛光、侵蚀、卷曲和短拖尾。需要查看完整轮廓时选择“完整构图”。
- 原色模式使用素材自己的颜色，不把用户图片或模型强制染成粉黄；没有原色的素材回退统一色。命名保存和 JSON 导入导出包含新样式。

## 实现与配置

新增 `grainStyle`，默认关闭。开启后独立增强表面暗部原色与亮核，使用较小的颗粒核心；局部侵蚀从固定原始位置生成相关空间场，被侵蚀的粒子在 fragment 中丢弃，避免透明孔洞仍遮挡后层。复用已有开放流场、粒子 `Points` 短尾和最终渲染画布，不新增圆圈线，也不新增积累式位置模拟。

旧花瓣参数显式关闭 `grainStyle`，白百合继承该值；通用预设和旧示例同样关闭，避免从新预设切回后遗留新样式。旧 JSON 缺少字段时由默认值补为 `false`。

| 参数 | 新预设值 |
| --- | --- |
| 数量 | 自动适配，上限 500,000；上限不代表固定实际绘制量 |
| 输出 / 颜色 | 1920 × 1080 / 素材原色 |
| 粒子大小 / 透明度 | 1.25 px / 96% |
| 泛光 / 亮度 / 对比 | 0.55 / 1.45 / 1.04 |
| 亮核比例 | 0.34 |
| 扩散 / 空间厚度 | 1.05 / 1.2 |
| 卷曲 / 侵蚀 / 流场尺度 | 1.65 / 0.86 / 1.65 |
| 拉丝 / 短拖尾 | 1.8 / 0.42 |
| 外围比例 / 运动速度 | 1.8% / 0.45 |
| 时间与末段 | 沿用 36 秒原形、侵蚀、黑场、反向聚合循环，开启淡出 |
