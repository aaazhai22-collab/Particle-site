# 空间粒子与时间轴系统修复

本轮依据用户的继续优化要求实施。保留图片和静态 GLB 导入、原色、六种效果、预设、720p 录制，重点修复图片消散呈整片拉伸以及时间轴编辑和播放状态问题。

## 实施与验收计划

1. 图片像素生成固定原坐标和颜色；GPU 按稳定随机种子与局部流场逐点改变 XYZ 位置。聚合仍准确组成原图，消散可从侧面看到空间厚度。空间厚度为零可保留平面运动。
2. 加入空间厚度、独立散开、错峰释放，提供深空漂移、错峰卷流预设。默认图片示例 60,000 粒子，12 秒关键帧循环；原百合 GLB 示例继续可用。
3. 区分时间轴播放和自由聚散；拖动暂停但不反复切换状态，按空格恢复当前任务。关键帧时间与总时长确认后提交，拒绝时间冲突；删除保持播放头，打帧读取点击瞬间的实际姿态。支持平滑、线性、保持过渡，首尾不同的循环明确提示。
4. 暂停静止时按需渲染，隐藏未录制页停止绘制；录制保留连续静止帧。验证实际录像、暂停、播放器定位，渲染帧率与编码帧率分开记录。
5. 执行自动测试、构建、浏览器 GPU/交互验证，并同步到既有 Site。尚未验证的项目保持待验收，发布成功以服务返回状态为准。

## 聚合竖条纹修复

旧 `sampleImagePixels` 将二维有效像素展开为一维后做位反转排列；截取粒子前缀时会与 736 像素等图片宽度产生周期共振，表现为每 16 / 8 列取点，聚合原图出现规则竖条纹。现先收集有效像素索引，用固定种子 xorshift 驱动 Fisher–Yates 洗牌，再取最多 100,000 个索引。每次导入只洗牌一次，复杂度 O(有效像素数)；同图结果确定、不重复，数量变化仍使用稳定前缀。

此修复不改变用户导入参数、Alpha 过滤、线性 RGB、居中比例或 GPU 空间参数。新增 736 × 981 参考尺寸与横纵采样覆盖回归已通过；真实聚合视觉、构建、录像与性能均已重新验证。旧源码包不得直接发布。

## 本轮配置与操作

- 默认用户参考 JPG：原色、60,000 粒子、2 px、95% 透明度、柔光 0.4、扩散 1.4、扰动 0.18、运动速度 0.7；深度 1.35、独立散开 0.8、错峰释放 0.5；侵蚀 0.72、流场 1.5、拉丝 1.55、拖尾 0.25，开启淡出；12 秒原形停留、侵蚀、淡出、反向还原片段，播放倍率 1。
- 百合 GLB 继续作为原色、80,000 粒子、12 秒立体模型示例；不与默认二维图片的配置或性能混用。
- 关键帧时间与总时长按 Enter 或失焦提交，Esc 取消；同刻移动拒绝并保留帧，删帧不移动播放头。新增帧读取点击瞬间实际姿态，接近已有时刻则复用。
- 每帧到下一帧可选平滑、线性或保持；旧 JSON 缺省平滑。循环首尾不同给出提示，整圈旋转或等价欧拉姿态视为相同端点，不自动更改用户数据。
- 底部区分时间轴与自由聚散，暂停 / 恢复延续对应任务。静止编辑按需渲染；隐藏且未录制时停止绘制与动画计时；录制持续捕获画布。

JPG 黑背景继续保留。PNG 完全透明像素不采样。素材、预设、截图与录像在本地处理；项目 JSON 不打包素材。

## 最终验证入口与真实证据（采样修复后）

本地应用为 `http://127.0.0.1:5173/`；开发专项页为 `/repair-qa.html`，生产入口不包含该页。点击运行后使用真实透明花朵 PNG 与原参考 JPG：验证原始坐标 Z=0、深度 0 / 1.2 侧面差异、六种 GPU 效果、0% 还原、12 秒片段三姿态、循环和暂停；活动编辑与录制按真实默认 60,000 粒子测量。

最终专项录制有效 11.3221 秒、墙钟 12.825 秒的 1280 × 720 / 目标 30 FPS 无声视频；暂停约 1.5 秒不计有效录像，暂停前后时间轴与运动时间准确不变。录制阶段不生成 PNG、不创建实体渲染器，每秒仅更新小状态。最终报告另存 `artifacts/repair-browser-test.json`，视频另存 `artifacts/repair-particles.mp4`。播放器从同一保存文件读取 1280 × 720，媒体时长 11.3043 秒；定位 5.65215 秒后播放至 6.061972 秒并暂停成功。
