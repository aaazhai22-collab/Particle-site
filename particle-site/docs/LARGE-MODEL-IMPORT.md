# 用户百合模型与大模型导入修复

2026-10-26：将用户提供的 `9f800fcfd1bf080d6bc2ec787faba287.glb` 加入「你的百合花束」预设，打开网站默认展示。原 GLB 为 83,730,068 字节（79.85 MiB）、1,500,000 三角面、850,405 顶点，包含双朵百合和茎叶。原先的 1,000,000 面限制是本次无法导入的直接原因。

## 导入容量

- GLB 文件上限由 100 MiB 提升为 256 MiB，三角面上限由 100 万提升为 500 万。
- 改用每网格描述符及 Float64 面积前缀数组；150 万面只需要约 12 MB 面积数组，避免为每个面创建独立 JavaScript 对象。
- 保留全部有效面的世界空间面积权重，不截断模型；分块返回浏览器，让加载反馈、相机和文件替换保持响应。
- 粒子只解码使用到的基础色贴图，跳过法线、粗糙度及高光等未参与粒子配色的贴图。基础色保持 2048 最长边采样上限，并在解码前检查 PNG/JPEG 尺寸。
- 保留原色、几何法线、局部分区和确定性样本。最大采样池仍为 500,000 粒子；预览实际绘制数由既有设备适配功能决定。

## 内置预设

`public/examples/uploaded-model.glb` 是适合网页加载的派生版本：12,593,180 字节、399,999 三角面、1 张内嵌 4K JPEG 基础色。保留模型形状、比例、UV、原色和双面材质。原始桌面文件未修改，SHA-256 和导出统计记录在 `uploaded-model-metadata.json`。可用 `scripts/export-uploaded-model.py` 重跑导出。

预设使用原色表面、300,000 自动数量上限及 36 秒渐蚀回环；左侧及导入窗口都可重新载入，也可下载网页优化 GLB。原始 150 万面文件可以直接从导入窗口加载，无需用户预先简化。
