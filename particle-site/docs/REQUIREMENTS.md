# 实时粒子视觉编辑器：需求与阶段计划

记录日期：2026-10-06。面向桌面浏览器中的视觉设计师，界面和操作说明使用中文。素材处理、参数保存与无声视频录制在浏览器本地完成。

## 本次范围

本次交付第一阶段可运行小样：内置彩色球体、GPU 粒子、三种聚散效果、视角操作、实时参数、播放控制，以及 1280 × 720 / 目标 30 FPS 的基础录制。所有展示的控制项必须连接真实功能；未实现的后续功能只出现在文档中。

第一阶段不实现图片或 GLB 导入，也不将内置球体误标为导入素材。`public/examples/` 提供后续阶段可使用的图片和静态模型样本。当前对话没有附上花朵参考视频文件；本阶段依据文字描述实现视觉方向，不能声称已经逐帧对照视频。

## 第一阶段需求

| 编号 | 需求 | 验收方式 |
| --- | --- | --- |
| S1-01 | 内置球体保留固定原始位置、原色和稳定随机种子；0% 精确回到原形 | 正向、反向拖动和重复聚散 |
| S1-02 | 左键旋转、滚轮缩放、右键平移；阻尼；重置视角与适配画面 | 浏览器手动操作 |
| S1-03 | 径向扩散、噪声漂浮、旋涡消散具有可辨认的差异 | 对照三个效果的中间与散开状态 |
| S1-04 | 聚散进度连续可逆；滑块操作暂停；支持消散、聚合、暂停/继续、往返循环 | 播放状态和端点检查 |
| S1-05 | 暂停停止聚散和粒子运动，但视角及参数操作仍生效 | 暂停后改变视角、颜色、大小 |
| S1-06 | 粒子数量、大小、颜色、透明度、扩散、扰动、运动速度、单程时长、倍率连接真实渲染 | 参数逐项调整 |
| S1-07 | 数量改变保留视角、进度、效果和播放任务，主要改变密度 | 在非零进度、播放中调数量 |
| S1-08 | 动画按时间计算；速度调整从当前状态继续；同一时间仅一个播放任务 | 运行中调速度与切换播放指令 |
| S1-09 | 散开时切换效果先平滑聚合，再应用并暂停；保留视角和通用参数 | 非零进度切换效果 |
| S1-10 | 内置球体、黑色背景、细密彩色粒子和柔和发光；发光须进入最终画布 | 预览与视频对照 |
| S1-11 | 独立 16:9 构图预览；720p、目标 30 FPS、能力检测、真实容器扩展名 | 录像元数据和播放器 |
| S1-12 | 录制至少 10 秒；停止后等待最后数据，生成视频，再开放预览和下载 | 完整录像流程 |
| S1-13 | 只录粒子画布；录制时视角变化和粒子效果可见，编辑面板、鼠标和 FPS 不入画 | 视频人工检查 |
| S1-14 | 显示状态、实际数量和短时平均渲染 FPS；中文错误提示；重复录制释放资源 | 状态和异常检查 |

## 初始参数约定

| 参数 | 目标范围 | 初始值 |
| --- | --- | --- |
| 粒子数量 | 1,000–100,000，步进 1,000 | 30,000 |
| 粒子大小 | 0.5–8 px（默认视角参考） | 2 px |
| 颜色 | 原色 / 统一色 | 内置球体原色 |
| 透明度 | 0–100% | 90% |
| 扩散距离 | 原形半径的 0–500% | 200% |
| 扰动强度 | 原形半径的 0–100% | 15% |
| 粒子运动速度 | 0–3 倍 | 1 倍 |
| 基础单程时长 | 0.5–20 s | 3 s |
| 播放倍率 | 0.25–4 倍 | 1 倍 |
| 发光 | 开关 / 强度 | 柔和发光 |
| 随消散淡出 | 开关 | 默认关闭 |

手动和自由播放的有效完整单程时长 = 基础单程时长 ÷ 播放倍率。模板录制在第五阶段采用独立阶段时间，不再叠加通用倍率。实现后的最终配置记录在 `PROGRESS.md`。

| 阶段 | 内容 | 进入下一阶段前的关键条件 |

## 后续需求约束

- 图片在三维空间中保持平面形态，侧面较薄属于预期；不做单图三维重建。
- GLB 只支持静态网格表面，不做骨骼动画、体积内部填充或完整高级材质。
- 所有效果统一 0–100% 进度和可逆位置；开启淡出时末段可不可见；聚合到 0% 清除历史拖尾。
- 流场侵蚀初始区间为 1–30% 边缘松动、30–65% 孔洞拉丝、65–90% 卷曲细流、90–100% 淡出，依据视觉验证调整。
- 原色模式保留素材颜色；统一色立即生效。参数重置保留素材。数量采样尽量稳定复用。
- 自由录像允许视角和实时调参；模板锁定打断时间线的操作。录制暂停同步暂停动画和模板计时，暂停时间不计有效时长。
- 录像捕获最终渲染结果，包含背景、发光、拖尾；固定真实输出像素，窗口或全屏变化不改变录像尺寸。
- MP4 仅在浏览器原生支持时提供，否则 WebM；无声；扩展名与容器一致。60 FPS 经测试后开放。
- 连续素材切换 20 次、播放 5 分钟、录像 5 次，检查可用性及资源增长；分别记录渲染 FPS 与视频编码帧率。
- 暂不包含账号、云端存储、动画模型、模型体积填充、图像三维重建或高级材质。
