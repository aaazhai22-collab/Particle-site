# 示例素材

这些文件用于粒子工坊的图片及静态模型示例；v0.2 已接入素材导入窗口。用户参考图片与程序化示例分别说明。本轮彩色百合模型正在制作与集成，当前结构 / 颜色 / 下载重导入验收待 QA。

## 彩色百合 3D 示例（本轮）

- `lily-reference.jpg`：用户百合参考图的本机副本，尺寸及文件大小待模型产物核对。
- `lily-model.glb`：目标为有曲面厚度的静态多网格模型，UV 基础色 PNG 内嵌于普通 glTF 2.0 GLB，无外部贴图或压缩解码依赖。
- `lily-model-metadata.json`：记录构成、统计、建模方法和近似范围，待生成后核对。
- 使用模型原色、80,000 粒子、12 秒聚散循环，可切换六效果并录制 720p 画布。
- 可下载 GLB 后重新通过工作台导入；真实下载、重新采样和颜色还原待 QA。
- 模型依据单张照片近似制作，背面、深度及遮挡面由建模推定，不是扫描或通用自动图片重建。
- 制作与浏览器处理均在本机完成，不需要将照片上传至第三方重建服务；详见 `docs/LILY-3D.md`。

## particle-flower-reference.jpg（保留的二维图片示例）

- 用户提供的花朵 JPG，736 × 981、RGB、87,822 字节。
- 黑背景属于原图像素，导入时保留整张图片；不会自动抠除。
- 聚合为二维薄平面，消散时进入三维空间。它与本轮单独构造的百合 GLB 是两种素材。

## color-flower.png

- 768 × 768 像素，RGBA PNG。
- 透明背景、粉色花瓣和橙黄色花蕊；适合检查透明像素过滤与原图取色。
- 已验证 Alpha 包含 0 和 255，并已打开图像检查外观。

## sample-sphere.glb

- glTF 2.0 二进制静态 GLB，不需要外部纹理文件。
- 一个球体几何网格，由三个节点实例化为中央球体和两侧小球。
- 节点包含不同平移、旋转和缩放，适合检查多网格世界变换及相对位置。
- 顶点颜色与标准基础材质可用于原色模式检查。
- 无动画、骨骼、压缩扩展或模型内部填充。
- Three.js GLTFLoader 已解析成功；非退化三角面朝外。

这两个文件不来自花朵参考视频；当前对话未附上参考视频。
