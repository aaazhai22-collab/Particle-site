# 秒制时间轴与关键帧

时间轴以秒定位。空白工程的基础片段为 6 秒：0 秒聚合、3 秒消散、6 秒重新聚合；应用默认图片示例使用另外的 12 秒片段，原色、60,000 粒子。百合 GLB 示例保留 80,000 粒子与自己的 12 秒片段。相邻关键帧可选择平滑、线性或保持过渡，关键帧处准确返回设定值；循环、动画计时与渲染由主应用和粒子引擎接管。

## 操作

1. 点击「播放 / 暂停」控制时间轴，点击「循环」决定结束后是否重复。
2. 拖动秒尺或轨道空白处定位当前画面；定位和关键帧编辑会暂停播放，便于精确调整。轨道获得焦点后，可用左右方向键微调、Home / End 跳到起止。
3. 点击任一轨道中的菱形选择关键帧，并聚焦形态、缩放或旋转的对应编辑。三类轨道共用同一组帧。
4. 点击「添加关键帧」，读取点击瞬间的实际画面姿态。时间按 0.01 秒对齐；距已有帧不超过 0.005 秒时复用该帧，不新增几乎重合的帧。
5. 在「选中关键帧」区域编辑时间、缩放、XYZ 角度和形态。关键帧时间与总时长先保存输入草稿，按 Enter 或离开输入框后提交，Esc 放弃草稿；输入中间数值不提前移动或裁剪帧。将帧移动到已有帧的时刻会提示冲突并保留全部帧。姿态参数修改即时展示；超范围值收敛到合法范围。
6. 点击垃圾桶删除选中帧。至少保留一帧；删除后保留当前播放头，不跳到其他剩余帧。
7. 在选中帧设置到下一帧的过渡：平滑缓入缓出、匀速线性或保持当前值后切换。循环首尾姿态不同会显示提示，系统不擅自修改用户帧；整圈旋转和等价欧拉姿态按相同端点判断。

## 数据与范围

- 总时长：0.5–120 秒。
- 关键帧时间：0–总时长。
- 整体缩放：0.1–4 倍。
- XYZ 旋转：每轴 -1080–1080°。角度直接插值，0→360° 是一整圈，0→720° 是两圈。
- 形态：内部保存为 0–1，0 表示聚合，1 表示消散；界面用语义描述，不显示聚散百分比。

`src/animation.ts` 导出 `DEFAULT_CLIP`、`normalizeClip(input)`、`retimeClip(clip, duration)` 与 `sampleClip(clip, time)`。数据结构为 `AnimationClip { duration, keyframes }`；每帧包含 `id / time / scale / rotation / progress`，可选 `interpolation: 'smooth' | 'linear' | 'hold'` 决定该帧到下一帧的过渡。缺省采用 smoothstep，兼容旧 JSON。每次从固定帧计算，不累积位置或角度误差。通过面板修改总时长时，按比例移动全部帧与播放头；例如 6 秒改为 3 秒时，0 / 3 / 6 秒变为 0 / 1.5 / 3 秒。

`normalizeClip` 返回独立副本，检查非有限数值、范围和唯一 ID，并按时间排序。它处理损坏导入数据时，同刻只保留最后输入的帧；空帧列表恢复按总时长缩放后的默认三帧。超出声明总时长的导入帧限制在终点，如重合则保留最后输入的一帧。这个导入清洗规则与面板主动编辑不同：面板拒绝时间冲突，保留已有帧。

## 当前限制

- 三条轨道共享关键帧与所选过渡，没有独立轨道曲线、贝塞尔曲线、撤销或重做。
- 时间按秒编辑，尚未提供按视频帧对齐功能。
- 两端没有关键帧时，首帧之前与末帧之后保持最近一帧的值。
- 循环首尾不同会提示，但不自动补齐姿态；连续循环应让首末形态和缩放相同，旋转姿态相同或相差整圈。
- 面板修改总时长会按比例重新分布帧；导入非法数据时仍通过 `normalizeClip` 限制超范围时间，同刻帧保留最后输入的一帧。
- 面板只通过回调修改数据；播放速度、动画与录制暂停协调、保存导出由主应用负责。

## 接口与布局

`TimelinePanel` 接收 `clip / time / playing / loop`，通过 `onClipChange / onSeek / onTogglePlay / onLoopChange` 控制主应用。可选同步 `getCurrentFrame` 优先读取点击瞬间的实际播放头与姿态，`currentSample` 作为兼容取样；`disabled` 禁用所有编辑与播放。引擎 `state.playbackSource` 明确区分 `timeline` 与 `free`，主界面据此显示和恢复当前任务。

布局为工具栏、左侧秒尺与三条轨道、右侧选中帧编辑区域，以及底部简短提示。推荐高度 180–230 像素。根类名为 `.animation-timeline`；关键类名为 `.timeline-toolbar`、`.timeline-body`、`.timeline-lanes`、`.timeline-ruler`、`.timeline-lane`、`.timeline-track`、`.timeline-keyframe`、`.timeline-playhead`、`.timeline-keyframe-editor`、`.timeline-fields`。样式由主应用统一提供。

主界面真实操作已验证：时间尺聚焦时按空格恢复当前任务；自由消散在终点按空格可反向聚合；底部播放从自由模式切回时间轴。将 0 秒帧移到已有的 1.8 秒被拒绝，仍保留 7 帧；总时长输入 18 时未确认前仍为 12，Enter 后按比例缩时为 18 秒。5 秒帧旋转改为 25° 实际生效，同刻打帧仍为 7 帧；删除后剩 6 帧，播放头仍为 5 秒。专项页另验证 12 秒三姿态、循环边界、暂停像素不变和录制暂停计时排除。尚未覆盖所有键盘、窗口或浏览器组合。
