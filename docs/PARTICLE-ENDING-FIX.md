# 花瓣微流·渐隐回环：末段拉丝修复

记录日期：2026-10-25（北京时间）。本轮只修复已有“花瓣微流·渐隐回环”在消散末段留下突兀圆圈线的问题：细丝沿实际粒子轨迹伸展，逐渐缩短、断开成碎点，再平滑淡出。生产代码变更限定为 `src/ParticleEngine.ts` 与 `src/shaders.ts`；预设入口、参数、素材、相机、36 秒时间轴及原有操作不变。

## 修复范围

旧尾层在粒子运动之外额外叠加 coil 圆弧，主体又在末段过早因 alpha 阈值丢弃，因此画面容易只剩明显的圆圈线。

现实现将变化限定在后段：进度不高于 0.65 时沿用原画面；0.65–0.78 之间旧线逐渐退场，新增独立 `Points` 层沿最多 1,000 个真实粒子的路径、每条 25 个历史采样点形成拉丝。稳定随机种子控制寿命与碎散，进度越靠后，路径逐步缩短并断成碎点；主体也保留相应的末段碎粒，随后一起淡出。位移与寿命从固定原始数据计算，反向定位不依赖已播放的历史。

0% 恢复原始形态并清除尾层；开启淡出时 100% 为完全黑场，包含泛光归零。关闭淡出时保留可见粒子，继续遵守原有开关语义。其他六种效果走原有分支。

操作仍然是选择已有“花瓣微流·渐隐回环”，使用原来的播放、暂停、时间定位、反向聚合与录制。没有新增控制项，也不改变预设的 36 秒周期。

## 首轮有损视频黑场检查

首轮录像保留为 [ending-recording-first.json](../artifacts/ending-recording-first.json) 与 [ending-first-particles.mp4](../artifacts/ending-first-particles.mp4)：7 项中 1 项未过。视频 5.1 秒黑场有 1,491 个达到测试亮度阈值的像素，平均归一化亮度约 0.000074292，没有粉色或黄色；原检查要求 `lit < 100`，因此失败，未删除该记录。

QA 仅将**有损编码视频帧**的黑场标准改为平均亮度 `< 0.0005`、发亮像素 `< 全帧0.2%`、粉色与黄色计数均为 0。**原始最终画布仍严格要求 `nonblack = 0`**，没有放宽渲染黑场或几何端点检查。第二轮实际视频黑场为 36 个发亮像素、平均亮度约 0.000001526、粉 / 黄均为 0，既满足有损视频容差，也实际满足原来的 `lit < 100`；它不是仅依靠放宽标准通过。

静态对照、真实 GPU 与录像共同验证本轮限定范围的保持、轨迹关联及端点行为。参考中的静态画面不足以确定完整时间变化，因此不承诺与参考逐帧 1:1。最终 TypeScript 与 Vite 生产构建已通过；是否上线仍以 Sites 部署工具的实际结果为准，不从测试通过推断已发布。
