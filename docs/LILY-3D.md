# 彩色百合 3D 粒子示例

记录日期：2026-10-07。状态：根据用户确认的方案制作与集成中，模型结构、浏览器视觉、重导入和录制验收均待本轮 QA；尚无本示例的实测 FPS 或新增测试通过数。

## 本轮目标

根据用户提供的百合参考图制作一个可下载、可重新导入的彩色静态 GLB，作为粒子工坊的三维示例。模型采用真实曲面与厚度、多网格和 UV 基础色贴图，包含正面、侧面和背面可观察的三维形态，避免把参考照片作为单张平面冒充模型。

这是根据单张参考图构造的**近似模型**。可见轮廓与颜色依据参考图，背面、遮挡部分和深度由建模推定，不能视为扫描结果或精确恢复真实花朵。本轮制作一个内置示例，不开放任意图片的自动三维重建功能。

此前的 `particle-flower-reference.jpg` 图片示例保留。图片仍是二维薄平面，JPG 黑背景保留；百合 GLB 则使用空间网格表面采样，两者不是相同的重建流程。

## 展示配置

- 目标显示 80,000 粒子，使用模型原色；固定稳定采样池，数量调整只改变密度。
- 12 秒关键帧循环：原形停留 → 流场侵蚀与卷曲拉丝 → 末段淡出 → 反向聚合还原，配合轻微缩放与素材旋转。
- 可切换径向扩散、噪声漂浮、旋涡、定向吹散、波浪和流场侵蚀六种效果，原色 / 统一色均可使用。
- 鼠标左键旋转相机、滚轮缩放、右键平移；可从侧面和背面观察。关键帧旋转作用于模型，相机操作独立。
- 保留 720p / 目标 30 FPS 自由录制。最终画布包含模型粒子、柔光、拉丝、短拖尾、淡出和视角变化，不录入控制面板。

12 秒展示循环是可编辑的普通关键帧片段，**不是第五阶段的独立自动录制模板**；自由录像仍需点击开始、暂停 / 继续、停止并生成。

## 本地处理与隐私

参考素材在本机建模，导入采样、参数保存及录像在浏览器本地完成，不需要把照片发送到第三方三维重建服务。GLB 将颜色贴图内嵌，重新导入只需一个模型文件。分享模型或项目文件由用户决定；项目 JSON 不包含原始素材。
