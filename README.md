# 粒子工坊 · v0.4 彩色流光与设备适配

在桌面浏览器中导入图片或静态 GLB，用六种粒子效果和秒制关键帧时间轴制作动画，并录制画布视频。计算、参数保存、截图及录制均在浏览器本地完成。

本轮增强**细密彩色流光、连续卷曲细丝与真正的画面泛光**，增加亮度、对比、亮核和卷曲控制。自动数量依据设备实际活动帧率增减，从 30,000 个起步、默认上限 300,000 个，最高可设 500,000 个；手动模式为 1,000–500,000 个。当前实际数量、有效上限和调节原因分别显示。录制冻结自动数量，手动模式允许自由调参。最新验收与性能见 [质感与设备适配记录](docs/EXPRESSIVE-PARTICLES.md)。

默认打开青铜方鼎原色模型与 16 秒展示循环；图片参考与彩色百合也可以在素材窗口一键加载。聚合时保持原形，消散时进入 XYZ 空间；图片聚合仍为平面像素阵列。此前空间消散与时间轴修复的历史证据见 [系统修复记录](docs/SYSTEM-REPAIR.md)，不作为新配置的性能结果。

**彩色百合 3D 示例**继续保留：根据用户参考图构造有厚度的静态多网格 GLB，内嵌 UV 颜色贴图，原色、12 秒聚散循环，并提供下载后重新导入。背面和遮挡处由建模推定，属于近似模型，详见 [百合 3D 记录](docs/LILY-3D.md)。

此前的 [花朵参考 JPG 图片示例](public/examples/particle-flower-reference.jpg) 保留，同样可展示原形停留、侵蚀卷流、淡出与反向还原，并编辑轻微缩放和旋转。

## 启动预览

在项目目录 `D:\azheng-codex\codex-Website` 打开终端。安装依赖后启动：

```powershell
pnpm install
pnpm dev
```

浏览器打开 <http://127.0.0.1:5173>。依赖已经安装时，只需运行第二条命令。关闭终端或按 `Ctrl+C` 会停止预览服务。端口 5173 被占用时，先关闭此前的预览服务。

如果电脑使用 npm，也可运行 `npm install` 与 `npm run dev`。已经安装依赖且可以直接使用 Node.js 时，可以绕过包管理器启动同一预览：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1
```

生产构建与本地查看构建结果：

```powershell
pnpm build
pnpm preview
```

构建命令包含 TypeScript 检查，静态输出位于 `dist/`。本地查看构建结果时，以终端显示的 URL 为准。

## 操作方法

1. 默认展示循环播放；按空格或底部播放按钮暂停。打开左侧“导入图片 / 3D 模型”，选择或拖入 PNG、JPG、JPEG、GLB，也可加载图片、三维组合或本轮百合示例。成功后替换场景，失败保留原素材；连续选择以最后一次为准。
2. 左侧选择径向扩散、噪声漂浮、旋涡消散、定向吹散、波浪消散或流场侵蚀。可应用“柔和漂浮”“能量爆散”“旋涡聚合”“参考视频风格”预设。
3. 底部时间轴以秒定位。拖动秒尺暂停并查看中间画面；“添加关键帧”读取点击瞬间的形态、缩放与 XYZ 素材旋转。点击菱形选择并聚焦对应字段；时间和总时长按回车或离开输入框后提交，Esc 取消。移动到已有帧时刻会明确拒绝，删帧保留当前播放头；总时长调整按比例移动全部帧。每帧可选择到下一帧的平滑、线性或保持过渡，循环首尾不同会提示。
4. 中央画面左键拖动旋转观察相机、滚轮缩放、右键拖动平移。按 `R` 或点击重置视角按钮恢复相机；“适配画面”让当前形态进入画面。关键帧旋转作用于素材，鼠标拖动作用于相机。
5. 右侧顶部选择自动或手动数量；自动模式的数值是上限，以“当前绘制”为实际数量。下方调整大小、原色 / 统一色、透明度、泛光、亮度、对比和亮核。空间厚度控制 Z 向运动，独立散开加强逐粒子的散射，错峰释放让不同区域先后松开。流场侵蚀还有侵蚀强度、流场尺度、方向、卷曲、拉丝、短拖尾和淡出；形态调整后可在当前时间打帧保存。
6. “粒子运动速度”控制流场变化，“播放倍率”控制动画推进；一键聚散使用“一键过渡时长 ÷ 播放倍率”，关键帧使用时间轴总时长。暂停后相机和参数仍可操作。

效果参数重置保留当前素材与关键帧。左侧可命名保存预设到浏览器本地；顶部可导入参数或导出项目 JSON，包含效果、参数和关键帧，不包含图片 / 模型文件。分享项目时需另行提供原素材。

预览下方的相机按钮导出当前 1280 × 720 PNG；全屏按钮隐藏控制面板，按 `Esc` 或点击“退出展示”返回。浏览器未允许原生全屏时，会回退为可退出的页面展示布局。

## 录制视频

1. 打开右侧“录制”页签，选择标准画质（请求 6 Mbps）或高画质（请求 12 Mbps）。浏览器会决定实际编码结果。
2. 点击“开始自由录制”。输出固定为 1280 × 720、目标 30 FPS、无声、16:9；窗口大小和全屏变化只改变显示尺寸。
3. 录制期间可以操作视角、调整参数和聚散，关键帧缩放 / 旋转也进入画面。录像只包含最终粒子画布，包括背景、柔光、拉丝、短拖尾及淡出；编辑面板、时间轴、鼠标光标和帧率文字不入画。
4. 动画暂停时录像继续，可以录下静止粒子与视角变化。点击“暂停录制”会暂停写入视频并同步暂停粒子动画，暂停时间不计入有效录像时长；继续录制恢复此前动画状态。
5. 点击“停止并生成”，等待最后数据收齐后自动打开视频预览。播放器支持播放、暂停和拖动进度，随后可以下载或返回编辑。

录制根据浏览器能力使用 MP4 或 WebM，文件扩展名与实际容器对应；不在浏览器中强制转码。单次限制为 120 秒和约 200 MB，容量可能多出最后一个完整编码块。再次录制会释放并替换上一次结果，请先下载需要保留的视频。

底部 FPS 是短时平均渲染帧率。暂停静止时按需渲染，低 FPS 可以表示没有重画相同画面；录制会持续输出静止帧。未录制的隐藏页暂停绘制与动画计时。目标 30 FPS、活动动画的实测渲染 FPS 和视频实际编码帧率属于不同指标；真实验证结果见下方项目记录。

## 示例图片与模型

这些文件可以通过素材导入使用：

- 本轮新增文件：`lily-reference.jpg`、`lily-model.glb`、`lily-model-metadata.json`，位于 `public/examples/`；普通静态 GLB、多网格、厚度与内嵌 PNG，生成及验收状态见 [百合说明](docs/LILY-3D.md)。
- [用户花朵参考 JPG](public/examples/particle-flower-reference.jpg)：736 × 981、RGB、87,822 字节；此前图片示例保留。
- [透明彩色花朵 PNG](public/examples/color-flower.png)：768 × 768，粉色花瓣和橙黄色花蕊，外围透明。
- [静态球体 GLB](public/examples/sample-sphere.glb)：三个球体节点，包含平移、旋转、缩放与顶点颜色，无外部文件依赖。
- [基础色贴图 GLB](public/examples/texture-plane.glb)：内嵌红 / 绿 / 蓝 / 黄 PNG，检查 UV 原色。
- [素材说明及验证](public/examples/README.md)。

用户 JPG 的黑色背景是原图像素，本版保留整张图片，不自动抠去黑色。图片聚合时是三维空间中的二维薄平面，消散时 GPU 对每个粒子计算空间位移；调高空间厚度后可从侧面检查深度。百合示例使用另外制作的立体网格，未开放任意图片的自动三维重建。PNG 的 Alpha 为 0 区域不生成粒子。实际花朵参考视频尚未提供，视觉依据文字与参考图片设计。

## 范围与项目记录

粒子计算、参数导出、截图和录像在浏览器本地完成，不上传素材和视频。该项目不包含账号或云端存储。

v0.2 已实现图片 / 静态 GLB 导入、六种 GPU 效果、流场参数与短拖尾、秒时间轴、形态 / 缩放 / 旋转关键帧、命名预设及项目 JSON 导入导出，保留 PNG 截图、展示视图和 720p 自由录制。原始阶段计划见需求文件；1080p、独立自动录制模板、60 FPS 录像开放及完整性能 / 稳定性验收仍属第五阶段待办。

**2026-10-23 最终验证**：Node 自动测试 **75/75**（含 736 × 981 图片采样分布回归）、真实 GPU **27/27**、采样修复后的图片与录像专项 **43/43** 通过；TypeScript 与 Vite 生产构建成功，主界面目视已去除竖条纹。时间轴已实际检查冲突拒绝、总时长确认与按比例缩时、同刻打帧不重复、删帧保持播放头，以及自由 / 时间轴暂停恢复。Three.js 分包体积警告没有阻止构建。

Windows / Chrome 155、Intel UHD（0x46A3）、60,000 原色 JPG 粒子、默认侵蚀与拖尾、720p 最终实测：编辑平均渲染 **58.75 FPS**，录像平均渲染 **54.6667 FPS**（包含暂停恢复时的 1 FPS 样本，保守均值）。生成无声 MP4 **4,424,597 字节**，有效录像 **11.3221 秒**、媒体 **11.3043 秒**；实际样本解析为 **335 帧、平均编码 29.6347 FPS**。暂停约 1.5 秒排除有效时长；同一文件已验证定位 5.65215 秒后播放至 6.061972 秒并暂停。16 CPU 线程和 32 GB 是浏览器报告，其中内存仅为估计值。详见 [最终专项报告](artifacts/repair-browser-test.json)、[GPU 证据](artifacts/repair-gpu.json)、[实际视频解析](artifacts/repair-video-inspection.json)、[最终 MP4](artifacts/repair-particles.mp4) 和 [主界面截图](artifacts/repair-workspace.jpg)。
